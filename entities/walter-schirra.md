# Walter M. Schirra Jr.

**Label: official.** Named in [NASA-UAP-D012](../records/nasa-uap-d012.md) as Sigma 7 pilot on Mercury-Atlas 8, October 3, 1962. The catalog says he described little white objects that tended to come from the capsule, called them particles and "lathe shavings," and described an unidentified burst of light he associated with sunset.

This page is not a biography. The argument about a "tag-along" object is [the case file](../cases/schirra-mercury-atlas-8.md). The catalog description does not use that word.
