# Project Blue Book

**Label: official.** Catalog descriptions in this release call Project Blue Book a U.S. Air Force program, 1952–1969, that investigated unidentified flying objects.

Files that say so include the Tremonton case file [DOW-UAP-D102](../records/dow-uap-d102.md), the photo file [D103](../records/dow-uap-d103.md), Blue Book correspondence [D096](../records/dow-uap-d096.md), Special Report No. 14 [CIA-UAP-015](../records/cia-uap-015.md), and the 1966–67 scientific advisory review [DOW-UAP-D092](../records/dow-uap-d092.md). Captain Edward Ruppelt's 1952 talk, [DOW-UAP-D154](../records/dow-uap-d154.md), describes the reorganization that the catalog says fed into Blue Book.

**Label: analysis.** This page is not a history of the project beyond those descriptions. The case file most readers want is [Tremonton](../cases/tremonton-1952.md).
