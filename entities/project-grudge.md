# Project Grudge

**Label: official.** [DOW-UAP-D017](../records/dow-uap-d017.md), the Sandia Base file for 1948–1950, says the file contains 209 sightings of "green orbs," "discs," and "fireballs" near the base, plus investigations of residual copper powder. It says a few of those investigations became the basis for Project Grudge, which collected reports from other installations and is also represented in the collection.

**Label: analysis.** This page does not go beyond that sentence. A full Grudge history is not reconstructed here.
