# AAWSAP

**Label: official.** The Advanced Aerospace Weapon System Applications Program. Catalog descriptions call it a Defense Intelligence Agency program active from 2008 to 2012. The contract papers and 37 DIRDs are in Release 06. The long write-up, with quotes, is the [case file](../cases/aawsap.md).

The short version: a July 2008 statement of objectives, a September 2008 award to Bigelow Aerospace Advanced Space Studies, five later modifications (the last of them extends performance to December 21, 2010), and technical reference papers the catalog says should not be read as validation of the ideas in them. Each DIRD description says it is one of 38. Thirty-seven are in the spreadsheet.

**Label: analysis.** The statement of objectives, the original award, and the first modification were already public through DIA FOIA before this release. Do not call the contract trail new. Whether the later modifications are new is unverified. The case file has the sources.
